ทฤษฎีบทพีทาโกรัส: สำรวจพื้นที่บนด้านทั้งสาม

ปรับสามเหลี่ยมมุมฉาก สำรวจพื้นที่ และจัดชิ้นส่วนเพื่อเชื่อมโยงความสัมพันธ์ของพื้นที่

ข้อมูลสำคัญ: คำตอบและผลการสำรวจของคุณจะไม่ถูกส่งออกไปทางอินเทอร์เน็ต ข้อมูลที่บันทึกไว้ในเครื่องนี้เป็นงานของคู่ของคุณ ควรดาวน์โหลดข้อมูลสำรองก่อนเปลี่ยนอุปกรณ์
ความคืบหน้า
ยังไม่ยืนยันคำตอบก่อนสำรวจ

1. คาดการณ์ก่อนสำรวจ

ก่อนเปิดพื้นที่สำรวจ ให้เลือกสิ่งที่คุณคาดการณ์ และเขียนเหตุผลของตนเอง

2. สำรวจและปรับสามเหลี่ยมมุมฉาก

ปรับ a และ b แล้วสังเกตว่า c และพื้นที่ของสี่เหลี่ยมทั้งสามเปลี่ยนอย่างไร มุมฉากคงเดิมเสมอ

b

ด้าน b4 ซม. · พื้นที่ 16 ตร.ซม.

3. จัดชิ้นส่วนพื้นที่

โหมดนี้ใช้ชิ้นส่วนหน่วยจากพื้นที่สี่เหลี่ยมบนด้าน a และ b เป็นตัวแทนพื้นที่จริงของสองสี่เหลี่ยมต้นทาง คุณสามารถเลือกชิ้นส่วนแล้วกดหมุน/ย้าย หรือใช้การจัดเรียงอัตโนมัติเป็นตัวช่วยหลังจากลองเองแล้ว

ขอบเขตของรูปแบบนี้: การจัดเรียงแบบชิ้นส่วนหน่วยทำงานเต็มรูปแบบเมื่อ a, b และ c เป็นจำนวนเต็มและมีค่า \(a^2+b^2=c^2\) เช่น 3–4–5, 5–12–13 และ 6–8–10 หากค่าปัจจุบันไม่เข้าเงื่อนไข โปรแกรมจะไม่แสดงภาพว่าเติมเต็มสำเร็จ แต่ยังสามารถดูพื้นที่ต้นทางและปลายทางได้
พื้นที่ต้นทาง a²- ตร.ซม.
พื้นที่ต้นทาง b²- ตร.ซม.
พื้นที่เป้าหมาย c²- ตร.ซม.
เลือกชิ้นส่วนในแผงต้นทาง แล้วใช้ปุ่มย้ายหรือหมุน

4. สรุปหลักฐาน

เขียนจากข้อมูลที่บันทึกไว้จริง แยกสิ่งที่สังเกตจากกรณีที่ทดลองออกจากการอธิบายความสัมพันธ์ทั่วไป

5. แบบฝึกระหว่างเรียน F1–F5

สำรวจข้อมูลให้ครบตามเกณฑ์เดิม และเขียนข้อสรุปพร้อมหลักฐานก่อนเปิดแบบฝึก
แบบฝึก F1–F5 ใช้สำหรับตรวจสอบระหว่างเรียนและให้ Feedback ไม่บวกคะแนนเข้าเกณฑ์ประเมินหลัก 10 คะแนนโดยอัตโนมัติ
ตรวจแล้ว 0/5 ข้อ คำตอบแก้ไขค้างตรวจ 0 ข้อ ยังไม่ครบเงื่อนไขต่อไป

F1: หาความยาวด้านและพื้นที่จากสามเหลี่ยมมุมฉาก

กำหนดสามเหลี่ยมมุมฉากที่มีด้านประกอบมุมฉากยาว a = 3 เซนติเมตร และ b = 4 เซนติเมตร จงหาความยาวด้านตรงข้ามมุมฉาก c และพื้นที่สี่เหลี่ยมจัตุรัสบนด้านทั้งสาม

F2: ความสัมพันธ์ของพื้นที่สี่เหลี่ยมบนด้านทั้งสาม

สามเหลี่ยมมุมฉากคู่ใดแสดงความสัมพันธ์ว่า ผลรวมพื้นที่สี่เหลี่ยมจัตุรัสบนด้านประกอบมุมฉากทั้งสองเท่ากับพื้นที่สี่เหลี่ยมจัตุรัสบนด้านตรงข้ามมุมฉาก?

F3: การเปลี่ยนความยาวด้านและพื้นที่

กำหนดสามเหลี่ยมมุมฉากที่ด้านประกอบมุมฉากด้านหนึ่งยาว 3 เซนติเมตร และอีกด้านยาว 4 เซนติเมตร หากเพิ่มด้านยาว 4 เซนติเมตรเป็น 5 เซนติเมตร โดยคงด้านยาว 3 เซนติเมตรไว้ ด้านตรงข้ามมุมฉากจะเปลี่ยนอย่างไร?

F4: การอ่านกราฟความสัมพันธ์ของพื้นที่

กราฟกำหนดแกนนอนเป็น a² + b² (ตารางเซนติเมตร) และแกนตั้งเป็น c² (ตารางเซนติเมตร) จุด (25,25) หมายถึงอะไร?

F5: การอธิบายและขอบเขตของหลักฐาน

ผู้เรียนทดลองสามเหลี่ยมมุมฉากหลายรูป และพบว่าผลรวมพื้นที่สี่เหลี่ยมบนด้านประกอบมุมฉากทั้งสองเท่ากับพื้นที่สี่เหลี่ยมบนด้านตรงข้ามมุมฉากทุกครั้ง ข้อสรุปใดเหมาะสมที่สุด?

ส่วนขยาย: จากการทดลองสู่การพิสูจน์

เมื่อพร้อม ผู้เรียนสามารถศึกษาการพิสูจน์ด้วยการจัดเรียงพื้นที่หรือใช้พีชคณิตเพิ่มเติม ส่วนขยายนี้แยกจากผลการตรวจ F1–F5 และไม่เพิ่มคะแนนอัตโนมัติ
